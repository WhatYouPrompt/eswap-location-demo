## 1. 产品概述

### 1.1 产品背景

ESwap 是一家专注于巴基斯坦市场的智能换电柜运营商，目前处于快速扩张期，主要覆盖拉合尔、卡拉奇、伊斯兰堡等核心城市。换电柜数量正在从早期的几十台向百台规模突破。

当前选址方式存在严重痛点：

| 痛点 | 描述 |
|------|------|
| 依赖人工经验 | BD团队靠"扫街"和直觉找点位，缺乏数据支撑，试错成本高 |
| 供需不匹配 | 现有点位偏离骑手核心活动热区，柜机利用率低，热点区域电池断供 |
| 基础设施盲区 | 电网稳定性、物业改造成本在前期勘察中被遗漏，导致签约后无法运营 |

### 1.2 产品定位

智能选址系统旨在将线下Excel流程搬到线上，通过数据可视化和智能评分，指导BD精准选址，提升审批效率，沉淀选址模型。

### 1.3 目标用户

| 角色 | 职责 | 核心场景 |
|------|------|----------|
| BD（商务拓展） | 录入潜在点位信息、照片、租金报价 | 线下踩点 → 系统录入 → 提交审批 |
| 城市经理/运营负责人 | 审批低分点位、复核决策 | 查看评分 → 线上审批 → 驳回/通过 |

### 1.4 用户规模

- 预计并发用户：10-50人
- 主要用户群体：巴基斯坦本地BD及城市经理

### 2.2 功能模块详细说明

#### 2.2.1 热力图可视化模块

**功能描述**：在地图上叠加骑手活跃度与现有电柜覆盖半径，直观暴露"需求真空区"。

**输入数据**：
| 数据项 | 来源 | 更新频率 |
|--------|------|----------|
| 骑手轨迹数据 | ESwap App API | T+1 |
| 现有电柜位置 | ESwap App API | 实时 |
| 电柜覆盖半径 | 系统配置 | 手动更新 |

**输出展示**：
- 热力图层：骑手活跃度热力分布（颜色深浅表示活跃程度）
- 覆盖层：现有电柜覆盖半径（圆形区域）
- 真空区标注：未被覆盖的高活跃区域标记

**交互功能**：
- 地图缩放/平移
- 图层切换（热力图/覆盖层/POI层）
- 点击区域查看详情（骑手数量、换电频次等）

**验收标准**：
- [x] 支持按城市筛选热力图范围（Demo聚焦拉合尔）
- [x] 热力图数据通过本地JSON加载
- [x] 支持3种活跃度层级显示（高/中/低）

> **Demo实现说明**：使用Leaflet.js + OpenStreetMap替代Google Maps，热力图使用圆形标记模拟，数据为Mock生成。

#### 2.2.2 智能评分推荐模块

**功能描述**：对BD录入的意向点位进行多维度打分（满分100分），并预测日均换电单量。

**评分模型**：

| 维度 | 权重 | 数据来源 | 评分规则 |
|------|------|----------|----------|
| 骑手活跃度 | 30% | ESwap API | 周边500m内骑手活动频次 |
| POI密度 | 25% | Google Maps API | 周边1km内餐厅/商圈/物流站点数量 |
| 租金成本 | 20% | BD录入 | 与城市平均租金对比 |
| 电网稳定性 | 15% | BD录入 | 1-5分评级（稳定=5分） |
| 竞品距离 | 10% | Google Maps API | 最近的竞品换电柜距离 |

**自动审批阈值**：
| 评分区间 | 处理方式 |
|----------|----------|
| ≥80分 | 自动通过，进入待签约状态 |
| 60-79分 | 推送城市经理人工审批 |
| <60分 | 系统建议驳回，BD可申诉 |

**输出内容**：
- 综合评分（0-100分）
- 各维度得分明细
- 预测日均换电单量
- 预测回本周期（月）
- ~~相似点位对比~~（Demo暂未实现）

**验收标准**：
- [x] 评分计算响应时间 < 3秒
- [x] 支持评分模型参数配置（constants/config.ts）
- [ ] 评分结果可导出（后续版本）

> **Demo实现说明**：骑手活跃度、POI密度、竞品距离使用Mock随机数据，租金和电网稳定性基于用户输入计算。

#### 2.2.4 ROI测算模块

**功能描述**：自动计算点位投资回报周期，辅助决策。

**计算公式**：

```
回本周期（月）= 柜机投入成本 / 月均净收益

月均净收益 = 预测日均换电单量 × 单次换电收益 × 30 - 月均运营成本
```

**输入参数**：

| 参数 | 来源 | 默认值 |
|------|------|--------|
| 柜机投入成本 | 系统配置 | 600,000 PKR |
| 混合ARPU | 系统配置 | 12,700 PKR/月 |
| 月均运营成本 | BD录入 | 35,000-55,000 PKR |
| 预测日均换电单量 | 评分模型 | Mock生成 |

**输出展示**：
- 预计回本周期（月）
- 月收入/月成本/月净利润
- 预测日均换电单量
- ~~月均收益预测曲线~~（Demo暂未实现）
- ~~敏感性分析~~（Demo暂未实现）

**验收标准**：
- [x] ROI计算支持参数配置
- [ ] 结果支持导出报告（后续版本）

> **Demo实现说明**：ROI参数已确定，计算公式为：回本周期 = 柜机成本 / 月净利润
